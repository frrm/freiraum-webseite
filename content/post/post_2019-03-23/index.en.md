We host several groups at Freiraum, such as Freifunk, amateur radio operators, and OSM. At the moment, each group communicates on its own mailing lists. Since Freiraum already uses a Matrix server through Carlo and we have had good experiences with it, we thought it would be useful to set up our own Matrix server and create channels for the different groups.

That would let us all see what the others are working on, discuss things quickly and informally, and give interested people a central place to start. At the moment, newcomers have to subscribe to the different mailing lists to get an insight into the groups' work, which we find cumbersome and not very timely.

Taking the idea further, it would be ideal if the server could be made available not just to Freiraum groups but also to other associations (technically oriented, IT-affine, etc.). That would create a hub for the Ulm region, helping with youth outreach and creating more synergies™ between associations.

Of course, it is important that each group retains control over its own channel. We do not want to gather other associations under Freiraum; we simply think we can gain more by moving communication to a shared platform, especially when it comes to reaching new members.

The idea has already been well received by Freifunk, at least. We will see in the coming period whether we can convince others too. Feel free to contact us (Contact > Matrix)!
