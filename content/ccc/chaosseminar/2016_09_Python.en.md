This talk is about the Python programming language. It gives a brief overview and answers a range of questions: what is the programming environment like? Why, for what, and how do people use Python? Why are there Python 2 and Python 3? What tasks is Python particularly suited for? What special language constructs does it have? What disadvantages and quirks should you be aware of?

Since there probably will not be enough time to cover everything, I will adapt the talk to the audience's interests.
