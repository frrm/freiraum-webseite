We hear everywhere about attacks on sensitive data (passwords, account details, credit card numbers, and so on). Since this is not a new problem, various methods have been developed to protect such data.

The talk focuses on applying these methods to protect data when using networked computer systems. Well-known security methods (SSL, SSH, Kerberos) will be examined through examples, and existing problems discussed.
