While Java 1.1 was designed to be extremely minimalist in its language features, each subsequent release added more extensions. Examples include anonymous and inner classes, assertions, enumerations, and generics.

This talk illustrates the language’s historical development from “too minimalist” to “quite usable”, while giving newcomers and those moving up to a newer version an overview of its new features and their advantages and disadvantages.
