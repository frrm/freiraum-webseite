dtrace is a tool, originally written by Sun, for tracing program execution in the kernel and userland. Scripts written in a language called D instrument programs at runtime, without requiring recompilation, and can collect all kinds of performance metrics using so-called probes. From Solaris, dtrace has since spread to BSD, Mac OS X, and even less common systems such as QNX, as well as applications such as Firefox. Today, dtrace is therefore the ideal tool for anyone who wants to know what their operating system or software is doing under the hood. The talk demonstrates how to use dtrace and how powerful it is, with many examples.
