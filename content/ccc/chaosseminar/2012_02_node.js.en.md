“Node’s goal is to provide an easy way to build scalable network programs. Almost no function in Node directly performs I/O, so the process never blocks.” (Source: http://nodejs.org/)

Despite being a relatively young project (it has existed since 2009), node.js has become enormously popular. It is developed on GitHub and has now surpassed the Ruby on Rails project in number of watchers.

We will discuss the motivation behind server-side JavaScript and introduce the node.js platform. What are the project’s characteristics? Why use JavaScript as the language? When does it make sense to work with it?

We will also introduce some practical libraries, such as socket.io, a cross-browser implementation of the WebSockets specification that makes it easy to create real-time web apps.
