How do you resist all the hype around “AI” and multi-level marketing schemes (aka “crypto”) and still build a BCI? This talk introduces brain-computer interfaces and demonstrates an implementation based on Elias Küchle's bachelor's thesis, supervised by Alexander Blöck. The thesis implemented the game 2048 and made it controllable using electroencephalography (EEG). The talk shows how to send ones and zeros through the human central nervous system and decode them again with (somewhat) reliable results.
