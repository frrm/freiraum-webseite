Java is more than a programming language. It is a phenomenon that even its critics acknowledge has made a difference to object-oriented programming and the platform independence of programs. This talk provides an overview of the key components of the Java 2 platform, discusses the features that distinguish Java from other programming languages, and serves as ideal preparation for the discussion that follows next time.
