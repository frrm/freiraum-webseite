[RIOT](http://projects.spamt.net/riot) is a C++ framework for scalable and efficient applications on hardware with parallel I/O and CPU resources.

Scalable means that the administrative overhead is almost negligible, so doubling the hardware resources nearly doubles the maximum throughput.

Efficient means that a resource never sits idle while there is work for it to do.

Alexander developed RIOT at logix-tt. A communications server for thousands of simultaneous clients over a cryptographic protocol runs there without problems using RIOT.
