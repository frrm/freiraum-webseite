We will introduce interesting and useful programs, command-line options, and features, some of which are unknown or simply very, very useful. The talk also aims to dispel the misconception that the console is dead and show everything you can do with and from the command line.

We presented the following programs in varying levels of detail:

- [tpp](http://www.ngolde.de/tpp/) - text presentation program
- [twin](http://linuz.sns.it/~max/twin/) - Terminal Window Manager
- [zsh](http://zsh.org) - no comment
  - [zsh enthusiasts](http://www.michael-prokop.at/computer/tools_zsh_liebhaber.html) - the zsh site par excellence
  - [schula's config](http://spamt.net/config/) - the configuration used for the talk
  - [The ZSH workshop](http://www.acm.uiuc.edu/workshops/zsh/) - a nice walk-through
- [perl](http://perl.org)
- [bb](http://aa-project.sourceforge.net/) - Ascii art foo
- [screen](http://www.gnu.org/software/screen/screen.html) - the ultimate terminal multiplexer
- [socat](http://www.dest-unreach.org/socat/) - the Swiss Army knife of networking (netcat++)
  - [Slides for socat](socat.tpp)
- [ipython](http://ipython.scipy.org/) - enhanced interactive Python shell

All of the above programs except bb are included in [grml](http://grml.org/), the best live CD for console users.
