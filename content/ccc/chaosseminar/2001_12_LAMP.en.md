In the age of e-commerce, database-driven web servers are a current topic beyond the CCC. Alongside an operating system and web server, the tools needed are a database and a suitable scripting language. The classic open-source setup combines Linux, Apache, MySQL, and PHP — LAMP for short. This talk gives an overview of the programs used and how they work together, and presents possible use cases for database-driven web servers.
