Perhaps no programming language has such a large gap between knowing it and being able to use it as C++. It began as “C with classes” and has since become one of the most complex languages used in practice.

The language gives developers powerful abstraction tools with extremely low runtime costs — provided the compiler is good. This makes C++ suitable for performance- or resource-critical applications that one wants to model using object-oriented techniques.

The language also has some ugly elements, some inherited from C and others due to performance or practicality. C++ is simply a pragmatic compromise.

The talk provides an overview of the language’s most important concepts. Given the limited time, some knowledge is assumed: object-oriented programming paradigms and C syntax.
