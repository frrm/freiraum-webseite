This month we have two short talks.

### git

**Speaker:** Christian Himpel  
**Time:** 20:00

Git is version-control software originally developed mainly for maintaining the Linux kernel.

In recent years Git has grown steadily in popularity, and a large developer and user community has formed around it.

Many projects have switched their version control from centralized SVN or CVS to distributed Git.

This talk gives an easy-to-follow introduction to distributed version control with Git. To make the switch from SVN and CVS easier, the key differences will be explained where appropriate. After introducing the most common concepts, typical workflows will be presented to show off Git’s advantages.

### Building an OS from scratch / CylonOS and PC-SYNNOS

**Speakers:** matou and phil  
**Time:** 20:45

How do you build a toy operating system? Lessons from the seminar of the same name.

The “Operating Systems from Scratch” seminar has been offered by the Institute of Distributed Systems at Ulm University for some time. It explores what an operating system actually has to do: memory management, scheduling, driver management, and more.

The special feature is that the seminar uses Java, which has not usually been used for low-level programming close to the hardware.

We will briefly present our approach and what we have achieved and implemented so far.
