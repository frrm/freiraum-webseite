The Extensible Markup Language is sometimes considered a successor to HTML. That is not really correct, because XML is a metalanguage that can be used to describe specific markup languages such as HTML. Almost every recent data format is based on XML, whether documents from the latest version of M$ Office, news feeds with RSS, or programming interfaces using SOAP or XML-RPC. The talk covers the basics of XML, explains terms such as XSL, DTD, SAX, and DOM, and shows a few example applications. By the end, the audience will (hopefully) understand that behind all the buzzwords used by marketing strategists lies a simple and robust technology.
