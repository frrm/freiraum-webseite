The talk is guided by questions such as “What is intuition? How can user interfaces be made as intuitive as possible?” (affordances, mappings, constraints, UI patterns) and “Could there be a better interface for this task?” (information content, Jef Raskin). The first part will focus on interfaces in general, with the later emphasis on software user interfaces.

I also want to discuss dark patterns in user-interface design: things you should never do.

And of course, we will look at some user-interface nightmares and ways to improve them, starting with our wonderful library software :).
