There is an extra talk in August about the Windows Vista network stack.

**Topics include:**

- General TCP ingredients (new features)
- Compound TCP
- Teredo (RFC 4380)
- Winsock Kernel Interface — WSK (Transport Data Interface)
- Firewalling (a complete overview of what is new)
- Windows Filtering Platform
- NDIS 6.0 (Receive Side Scaling, TCP Chimney Offload)
