Under the hood of every Linux distribution — except Debian GNU/Hurd — runs the Linux kernel. The talk briefly introduces why a kernel is needed and how it works. Code examples explain how to give the kernel a kick using your own C code. Several tools for Linux kernel development will also be shown.

Due to the amount of material, the talk is split into parts. Part one covers:

- Operating system basics
- Required tools
- Configuration and compilation
- Differences from C application programming
- The Linux boot process
